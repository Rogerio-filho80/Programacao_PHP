# Programacao_PHP

# 📘 Programação em PHP

Este repositório contém o material de estudo e exercícios da **Escola da Amazônia** sobre Programação em PHP, focado em lógica de programação e desenvolvimento web básico.

## 📁 Estrutura do Projeto

O projeto está organizado em módulos sequenciais:

- **00 - Introdução**:
  - Configuração do ambiente (XAMPP).
  - Fundamentos do PHP e HTML.
  
- **01 - Lógica de Programação**:
  - Variáveis, operadores e condicionais (`if/else`).
  - Exercícios de fixação.
  
- **02 - Laços de Repetição**:
  - Estruturas `for`, `while` e `do/while`.
  - Controle de fluxo (`break`, `continue`).

- **03 - Vetores e Matrizes**:
  - Arrays uni e multidimensionais.
  - Funções nativas (`sort`, `count`).

- **04 - Funções**:
  - Criação e invocação de funções.
  - Parâmetros e retorno de valores.

- **05 - Desenvolvimento Web**:
  - Formulários HTML (`<form>`).
  - Método GET e POST.
  - Superglobais (`$_GET`, `$_POST`, `$_SESSION`).

- **06 - Orientação a Objetos**:
  - Classes, objetos e propriedades.
  - Métodos, `new` e `$this`.
  - Encapsulamento (`public`, `private`, `protected`).
  - Herança e polimorfismo.

- **07 - Arquivos e Pastas**:
  - Manipulação de arquivos com `fopen()`, `fwrite()`, `fread()`, `fclose()`.
  - Excluir (`unlink()`) e renomear (`rename()`).
  - Criar pastas (`mkdir()`).

- **08 - Bancos de Dados**:
  - Introdução ao MySQL.
  - Conexão e execução de consultas SQL.

- **09 - Projeto**:
  - Projeto final integrando todos os conceitos aprendidos.

## 🚀 Como Usar

1. **Instale o XAMPP**: Para rodar os arquivos PHP localmente.
2. **Clone o repositório** ou baixe os arquivos.
3. **Acesse** pela URL no navegador, ex: `http://localhost/NomeDaPastaDoExercicio/`
